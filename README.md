# Game-Hub
Python Tkinter casino game hub built in Jupyter Notebook with multiple mini-games, balance tracking, jackpots, daily rewards, and VIP progression. Includes Slots, Blackjack, Dice Duel, Coin Flip, High-Low, Bomb Defuse, Rock-Paper-Scissors, and a lucky spin wheel.

# Ultimate Casino Hub - Deluxe Edition

A fun Python game project built with **Tkinter** inside a **Jupyter Notebook**.  
This project combines multiple casino-style mini-games into one interactive desktop-style app with a colorful interface, balance tracking, jackpots, bonuses, and progression features.

## Features

- Lucky Spin Wheel
- Mega Slots
- Blackjack 21
- Rock-Paper-Scissors
- Bomb Defuse
- Dice Duel
- Coin Flip
- High-Low Cards
- Daily Bonus rewards
- Jackpot system
- VIP level progression
- Win/loss and earnings tracking
- Animated GUI elements

## Tech Stack

- Python
- Tkinter
- Jupyter Notebook
- Random / Math / Time modules

## How to Run

1. Open the notebook file:
   `basic project game.ipynb`

2. Run all cells in Jupyter Notebook.

3. Make sure Python supports **Tkinter** on your system.
